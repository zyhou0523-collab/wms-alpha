# WMS PC V2.0 发布说明

## 一、版本概述

WMS PC V2.0 是当前 WMS Alpha PC 端完整阶段版本，在 V1.5 的入库管理、出库 / 发货管理、数据驾驶舱和数据报表基础上，追加库存管理核心能力，重点补齐库存移动、库存盘点和库存查询快捷移动入口。

本版本用于 PC 端 Web 原型演示、业务评审、GitHub 分支归档，以及后续 PDA / 移动端作业、真实 SAP / MES / 履约系统接口联调的基础版本。

## 二、版本范围

V2.0 继承 V1.5 的主要能力：

- 入库管理：预期到货通知单、主子结构列表、SN 采集 / 托盘箱码绑定、收货确认、取消收货、SAP 入库回传与重传、导入导出。
- 出库 / 发货管理：发运订单、库存分配、人工指定分配、拣货、发货、取消分配、取消拣货、取消发货、订单关闭、部分发运、分单处理、SAP 出库回传。
- 数据驾驶舱：全球库存看板、KPI 指标、世界地图库存分布、全球 / 地区部 / 仓库层级穿透、安全库存预警、呆滞库存预警、出入库趋势。
- 数据报表：进出存报表、入库日报表、出库日报表、标准库龄报表、分段库龄报表、出库 SN 报表、入库 SN 报表。
- 基础能力：产品主数据、客户 / 供应商 / 货主主数据、仓库设置、接口日志、操作日志、多货主库存模型。

## 三、V2.0 新增功能

- 新增库存移动列表和移动单详情。
- 新增库存查询页面快捷库存移动入口。
- 新增库存盘点列表、盘点单创建、盘点快照、盘点记录、差异确认和库存调整。
- 新增库存移动和库存盘点相关库存流水。
- 新增库存移动和库存盘点相关操作日志。
- 强化库存、SN、货主、仓库、库位、托盘码、箱码之间的数据联动。

## 四、库存移动功能说明

库存移动支持以下业务场景：

- 库位移动。
- 托盘变更。
- 箱码变更。
- 包装重绑。
- 综合移动。

核心规则：

- SN 管理产品必须按 SN 移动，移动数量固定为 1。
- 非 SN 管理产品按数量移动，支持部分移动。
- 一次快捷移动限制同一货主、同一仓库。
- SN 管理产品和非 SN 管理产品不混合在同一个快捷移动单中处理。
- 冻结库存不可移动。
- 已分配、已拣货、已发货库存不可移动。
- 目标库位必须存在、启用且未冻结。
- 移动确认后更新库存、SN 当前库位、托盘码、箱码和包装绑定关系。
- 移动确认后写入库存流水和操作日志。

## 五、库存盘点功能说明

库存盘点支持以下业务范围：

- 全盘。
- 指定仓库盘点。
- 指定库区盘点。
- 指定库位盘点。
- 指定产品盘点。
- 指定货主盘点。
- 指定批次盘点。
- 指定托盘盘点。
- 指定 SN 盘点。

核心规则：

- 盘点单创建后生成盘点快照。
- SN 管理产品按 SN 盘点。
- 非 SN 管理产品按数量盘点。
- 支持盘盈、盘亏、库位差异、SN 差异识别。
- 支持差异确认和库存调整生效。
- 库存调整后写入库存流水和操作日志。

## 六、演示路径

建议演示顺序：

1. 打开 `库存管理 / 库存查询`，按仓库、货主、产品、库位、托盘码或箱码筛选库存。
2. 在库存查询列表勾选一条或多条同货主、同仓库库存。
3. 点击【库存移动】，系统自动带出来源库存信息。
4. 填写目标库位、目标托盘码或目标箱码。
5. 点击【确认移动】，系统创建库存移动单并确认移动。
6. 打开 `库存管理 / 库存移动`，查看移动单和移动明细。
7. 打开 `库存管理 / SN 查询`，检查 SN 管理产品的库位、托盘码、箱码是否同步更新。
8. 打开库存流水或移动详情，查看移动流水和操作日志。
9. 打开 `库存管理 / 库存盘点`，新建盘点单。
10. 生成盘点快照，录入盘点结果，确认差异并执行库存调整。

重点菜单：

- `库存管理 / 库存查询`
- `库存管理 / 库存移动`
- `库存管理 / 库存盘点`
- `库存管理 / SN 查询`

## 七、启动方式

```bash
git clone https://github.com/zyhou0523-collab/wms-alpha.git
cd wms-alpha
git checkout release/wms-pc-v2.0

docker compose up -d mysql

cd backend
mvn spring-boot:run

cd ../frontend
npm install
npm run dev
```

访问地址：

- 前端：http://localhost:5173
- 后端：http://localhost:8080
- Swagger：http://localhost:8080/swagger-ui/index.html
