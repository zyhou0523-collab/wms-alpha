# WMS Mobile V1.0 发布说明

## 一、版本概述

WMS Mobile V1.0 是 WMS Alpha 项目的 PDA / H5 移动端首个阶段版本，基于 WMS PC V2.0 的后端能力和业务数据模型，提供面向手持 PDA、安卓扫码终端和移动浏览器的现场作业入口。

本版本不新增 PC 端业务能力，重点是完成移动端工程、基础页面、公共能力和 H5 / PDA 竖屏适配，为后续入库、出库、库存移动、库存盘点和扫码枪适配打基础。

## 四、移动端页面说明

- 登录页：提供移动端账号密码登录入口，复用 WMS Alpha 默认演示账号。
- 首页：展示 WMS Alpha PDA 标识、当前仓库、登录用户、今日待办和作业入口。
- 入库页：已完成基础页面和入口，后续继续完善 SN 采集、收货、上架等业务闭环。
- 出库页：已完成基础页面和入口，后续继续完善拣货、发货等业务闭环。
- 库存页：已完成库存查询、库存移动、库存盘点、SN 查询入口，后续继续完善现场作业流程。
- 我的页：提供移动端用户信息和退出能力入口。

## 五、启动方式

```bash
cd mobile
npm install
npm run dev
```

本机访问：

```text
http://127.0.0.1:5174
http://127.0.0.1:5174/home
```

构建检查：

```bash
npm run build
```

## 六、H5 / PDA 预览方式

桌面浏览器直接访问移动端页面时，页面会以最大 430px 的移动端容器居中展示，模拟手机 / PDA 竖屏效果。

Chrome 手机模式建议尺寸：

- iPhone 12
- Pixel 5
- 自定义 `430 x 932`

局域网真机 / PDA 访问：

```bash
npm run dev -- --host 0.0.0.0
```

然后在同一局域网的手机或 PDA 上访问：

```text
http://电脑局域网IP:5174
```

## 七、与 PC V2.0 的关系

WMS Mobile V1.0 基于 WMS PC V2.0 的业务模块、后端接口和数据库模型进行移动端入口建设。PC V2.0 仍是当前完整 PC 演示版本，Mobile V1.0 是独立的移动端阶段发布分支，不覆盖 `main`、`release/wms-pc-v1.5` 或 `release/wms-pc-v2.0`。
