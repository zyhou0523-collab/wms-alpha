# WMS Alpha 到正式版工程化路线

## 阶段 1：Alpha 原型可演示

- 完成 Vue3 + Element Plus 后台框架。
- 完成 Spring Boot REST API。
- 完成 MySQL schema 和 seed 演示数据。
- 完成主数据、仓库、库位、库存、SN、入库、出库、接口日志、看板页面。
- 支持前端 Mock 演示和后端 Mock 接口日志。

## 阶段 2：业务闭环增强

- 入库：收货、SN 校验、托盘/箱/SN 绑定、上架。
- 出库：FIFO 分配、扫码拣货、复核、发货。
- 库存：移动、冻结、调整、盘点、库存流水。
- SN：状态流转、完整追溯链路、售后/RMA 校验。
- 接口：失败重试、幂等键、请求报文详情、补偿操作。

## 阶段 3：工程化治理

- 引入 MyBatis Plus 或 JPA 分层仓储。
- 引入 JWT、RBAC、数据权限和审计。
- 增加 OpenAPI 契约测试、后端单元测试、前端组件测试。
- 增加 Docker Compose 一键部署。
- 增加 CI、代码扫描、数据库迁移工具 Flyway/Liquibase。

## 阶段 4：真实系统集成

- SAP：生产工单、库存过账、VMI 结算。
- MES：SN 下发、生产报工、质量状态。
- 履约：发运订单、物流回传。
- CRM/销售易：客户、销售订单和售后单。
- 追溯：SN 出库回传和售后追溯。

## 阶段 5：正式版能力

- PDA/移动端扫码作业。
- 波次、路径优化和补货策略。
- 标签打印模板和打印机驱动。
- BI 报表和可配置看板。
- 高可用部署、监控告警、性能压测。
