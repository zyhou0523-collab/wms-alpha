# WMS Alpha 演示脚本

## 1. 演示目标

验证 WMS Alpha 可以跑通核心链路：

MES 下发 SN -> 预期到货通知单（生产入库类型）-> 收货时选择目标库位 -> SN/箱/托盘绑定 -> 库存查询 -> 发运订单（销售出库类型）-> 库存分配 -> 拣货 -> 复核 -> 发货 -> SN 回传追溯 -> SAP 扣账 Mock -> 看板更新。

## 2. 准备数据

| 数据 | 示例 |
|---|---|
| 产品 | `GT3-30KD1R11001` |
| 仓库 | `WH-HZ-CENTRAL` |
| 库位 | `A01-01-01` |
| SN | `SN-GT3-0001` 到 `SN-GT3-0010` |
| 托盘码 | `PLT202606110001` |
| 箱码 | `BOX202606110001` |
| 预期到货通知单 | `IN202606110001` |
| 发运订单 | `OUT202606120001` |
| 客户 | `CUST-TESLA-001` |

## 3. 入库演示

操作路径：入库管理 -> 预期到货通知单

1. 查询 `IN202606110001`，确认列表只显示一行主表数据。
2. 点击“查看”，确认详情页包含单据主信息、入库明细、SN 明细、操作记录、接口日志。
3. 在列表操作列点击“采集 SN”，不跳转详情页，直接打开订单维度“SN 采集 / 托盘箱码绑定”窗口。
4. 单产品订单自动选中唯一产品明细；多产品订单先选择“行号 / 产品明细”，系统带出产品 ID、产品编码、产品名称、预期数量、已收数量和剩余可采集数量。
5. 录入托盘码、可选箱码，并粘贴 `SN-GT3-0001` 到 `SN-GT3-0010`。
6. 点击“校验”，确认数量未超过当前产品行剩余数量，且 SN 产品、状态、绑定关系均通过校验。
7. 点击“确认采集”，系统生成 SN/箱/托盘/ASN/明细行绑定关系，产品行已收数量更新，列表聚合已收数量和状态刷新。
8. 点击“查看”进入详情页，确认“入库明细”行级“采集 SN”入口仍可用，SN 明细和箱托绑定记录已刷新。
9. 打开“入库管理 -> SN 绑定”，按 ASN 单号或 SN 查询绑定关系。
10. 选择一条错误绑定，点击“删除”或“批量删除”，系统释放 SN 明细行关联并回退行已收数量；再回到预期到货通知单详情重新采集。
11. 点击“SAP回传”，接口日志记录 `SAP_INBOUND_POSTING`，单据关闭。

## 4. 出库演示

操作路径：出库管理 -> 发运订单

1. 查询 `OUT202606120001`，确认列表只显示一行主表数据。
2. 点击“查看详情”，确认产品明细在详情页子表中展示。
3. 点击“库存分配”，执行系统自动 FIFO 分配。
4. 生成拣货任务。
5. 扫码完成拣货。
6. 扫码完成出库复核。
7. 录入承运商、物流单号、发货人和发货时间，确认发货。
8. 验证库存扣减、SN 状态变为已出库、追溯回传和 SAP 扣减日志写入。
9. 打开数据驾驶舱，确认库存数量同步下降。

## 5. 异常演示

- 入库 SN 重复录入：在产品行 SN 采集弹窗内重复录入同一 SN，校验结果提示本次录入重复。
- 入库 SN 超量采集：在计划数量为 10、已收数量为 0 的产品行录入 11 个有效 SN，系统提示超过剩余可采集数量。
- 入库 SN 产品不匹配：在当前产品行为 `GT3-30KD1R11001` 时录入其他产品已存在 SN，系统提示产品不一致。
- 入库绑定删除重采：在 SN 绑定列表删除错误关系后，回到预期到货通知单详情的产品行重新采集。
- 出库库存不足：选择库存不足发运订单，执行自动分配，系统生成分配异常。
- 出库 SN 不匹配：拣货时扫描不属于当前订单的 SN，系统提示不匹配。
- SAP/追溯失败：发货确认时勾选失败模拟，接口日志显示失败原因并支持重试。

## 6. 评审关注点

- 入库/出库菜单是否收敛到统一二级菜单。
- 列表是否按单据主表展示，而不是按明细行展开。
- 详情页是否体现主表 + 明细 + 日志的主从结构。
- 入库是否取消独立上架动作，改为收货时选择目标库位。
- SN 绑定列表是否支持筛选、复选、批量删除和重新采集。
