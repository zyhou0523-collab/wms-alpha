# WMS PC V2.0.1 发布说明

## 一、版本概述

WMS PC V2.0.1 是在 WMS PC V2.0 基础上的系统管理增强版本。本版本不改变入库、出库、库存、驾驶舱、报表等核心业务闭环，重点补齐企业级后台管理能力，使 WMS PC 端更接近若依 RuoYi 风格的系统管理结构。

## 二、版本范围

本版本继承 V2.0 的核心能力：

- 入库管理：预期到货通知单、SN 采集、托盘箱码绑定、收货确认、取消收货、SAP 入库回传与重传。
- 出库 / 发货管理：发运订单、库存分配、人工指定分配、拣货、发货、取消分配、取消拣货、取消发货、部分发运、分单处理、SAP 出库回传。
- 库存管理：库存查询、SN 查询、库存移动、库存查询快捷移动、库存盘点、库存流水。
- 数据驾驶舱：全球库存看板、KPI 指标、世界地图库存分布、全球 / 地区部 / 仓库层级穿透、安全库存预警、呆滞库存预警。
- 数据报表：进出存、入库、出库、库龄、SN 等报表。

## 三、V2.0.1 新增功能

- 系统管理一级模块补齐。
- 新增用户管理、角色管理、菜单管理、部门管理、岗位管理。
- 新增字典管理、参数设置、通知公告。
- 新增操作日志、登录日志。
- 新增字段管理、数据权限。
- 新增系统管理入口下的接口日志。
- 新增系统管理相关数据库表和演示 seed 数据。

## 四、系统管理模块说明

系统管理菜单包括：

- 用户管理
- 角色管理
- 菜单管理
- 部门管理
- 岗位管理
- 字典管理
- 参数设置
- 通知公告
- 操作日志
- 登录日志
- 字段管理
- 数据权限
- 接口日志

页面风格参考若依 RuoYi，包含查询区、工具栏、表格、分页、状态标签、新增、编辑、删除、详情查看等基础交互。

## 五、用户管理功能说明

用户管理支持维护：

- 用户账号、姓名、昵称
- 部门、岗位
- 主角色
- 仓库范围
- 货主范围
- 默认仓库
- 默认货主
- 手机号、邮箱、状态、备注

同时支持重置密码和分配角色，用于演示 WMS 多角色、多仓库、多货主的人员权限结构。

## 六、角色与菜单权限说明

角色管理支持维护角色编码、角色名称、数据范围、仓库范围、货主范围和状态。角色可分配菜单权限，菜单树覆盖当前 WMS PC 的主菜单、二级菜单和部分按钮权限标识。

演示角色包括：

- 系统管理员
- WMS 主管
- 入库操作员
- 出库发运员
- 库存管理员
- 主数据管理员
- 接口管理员
- 货主查看员

## 七、字段管理与数据权限说明

字段管理覆盖 WMS 核心页面字段配置，包括入库、出库、库存、SN、报表和系统页面，可维护字段显示、必填、可编辑、排序和角色范围。

数据权限支持按部门、仓库、货主维度配置，当前版本以配置和演示为主，业务 API 的强制拦截将在后续增强。

## 八、操作日志与登录日志说明

操作日志复用 WMS 业务操作日志能力，覆盖入库、出库、库存移动、库存盘点、SAP 回传和系统管理动作。

登录日志新增 `sys_login_log` 表，提供用户登录成功、失败、IP、浏览器、操作系统和消息记录，用于演示审计入口。

## 十、启动方式

```bash
git clone https://github.com/zyhou0523-collab/wms-alpha.git
cd wms-alpha
git checkout release/wms-pc-v2.0.1

docker compose up -d mysql
mysql -uroot -p123456 < sql/01_schema.sql
mysql -uroot -p123456 wms_alpha < sql/02_seed_master_data.sql

cd backend
mvn spring-boot:run

cd ../frontend
npm install
npm run dev
```

前端 Mock 演示：

```bash
cd frontend
npm install
VITE_USE_MOCK=true npm run dev
```

## 十二、已知问题
