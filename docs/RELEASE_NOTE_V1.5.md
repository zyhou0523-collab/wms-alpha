# WMS PC V1.5 Release Note

## 一、版本概述

WMS PC V1.5 是 WMS Alpha 项目 PC 端阶段版本，重点补齐发货管理、数据驾驶舱看板和数据报表能力，形成可演示、可评审、可继续工程化迭代的 PC 端原型。

## 二、本次主要迭代内容

1. 发货管理模块：发运订单、库存分配、拣货、发货、取消发货、订单关闭和 SAP 回传。
2. 数据驾驶舱看板：全球库存看板、KPI 指标、世界地图、库存预警和层级穿透。
3. 数据报表：进出存、入库日报、出库日报、标准库龄、分段库龄、出库 SN、入库 SN。

## 三、核心功能清单

- 入库管理 / 预期到货通知单
- SN 采集 / 托盘箱码绑定
- 入库收货 / 取消收货
- SAP 入库回传
- 出库管理 / 发运订单
- 库存分配 / 人工指定分配
- 拣货 / 取消拣货
- 发货 / 取消发货
- 订单关闭 / 订单取消 / 部分发运分单
- SAP 出库回传
- 库存查询 / SN 查询
- 多货主库存管理
- 数据驾驶舱 / 工作台
- 报表中心 / 数据导出

## 四、演示路径

1. 打开数据驾驶舱，查看全球库存看板、KPI 指标和库存预警。
2. 进入入库管理 / 预期到货通知单，演示 SN 采集、收货、取消收货和 SAP 回传。
3. 进入出库管理 / 发运订单，演示分配、拣货、发货、取消发货和关单。
4. 进入库存管理，查看库存查询和 SN 查询。
5. 进入报表中心，查看进出存、入库日报、出库日报、库龄和 SN 报表，并执行导出。

## 五、启动方式

```bash
cd wms-alpha
docker compose up -d mysql

cd backend
mvn spring-boot:run

cd ../frontend
npm install
npm run dev
```

前端 Mock 演示：

```bash
cd frontend
npm install
npm run dev
```

如需固定使用本地 Mock，可在 `.env` 或启动环境中设置：

```text
VITE_USE_MOCK=true
```
