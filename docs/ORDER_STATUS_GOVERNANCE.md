# WMS 出入库订单状态治理说明

本文档记录 `release/wms-pc-v2.2` 本轮“出入库订单状态治理基础优化”的口径。目标是统一状态字典、页面筛选、页面显示和多语种词条，不调整入库收货、出库分配/拣货/发货、SAP 回传触发时机。

## 1. 状态治理背景

历史版本中，发运订单与预期到货通知单状态散落在前端页面、mock 数据、seed 数据和少量后端代码中。部分状态同时承担业务进度和接口结果含义，例如旧发运状态 `CALLBACK_SUCCESS/CALLBACK_FAILED`，以及旧入库状态 `SAP_FAILED`。本轮将订单主状态和 SAP 回传状态分离治理，并通过系统字典和 i18n 词条形成统一显示口径。

## 2. 发运订单主状态

| 状态编码 | 中文名称 | 说明 |
| --- | --- | --- |
| CREATED | 创建 | 新建发运订单后的标准初始状态。 |
| PARTIAL_ALLOCATED | 部分分配 | 部分计划数量已完成库存分配。 |
| ALLOCATED | 完全分配 | 全部计划数量已完成库存分配。 |
| PARTIAL_PICKED | 部分拣货 | 部分数量已完成拣货。 |
| PICKED | 完全拣货 | 全部数量已完成拣货。 |
| PARTIAL_SHIPPED | 部分发运 | 部分数量已完成发货确认。 |
| SHIPPED | 完全发运 | 全部数量已完成发货确认。 |
| CLOSED | 订单关闭 | 用户关闭订单后的终态，当前关闭时触发 SAP 回传。 |
| CANCELED | 订单取消 | 订单取消终态。 |

## 3. 发运订单兼容状态

以下状态保留显示和筛选能力，但在字典备注、页面筛选和文档中标记为兼容状态，不作为新主流程推荐状态。

| 状态编码 | 中文名称 | 兼容原因 |
| --- | --- | --- |
| PENDING_ALLOC | 待分配 | 旧 demo/旧接口待分配状态。 |
| PICKING | 拣货中 | 旧拣货任务状态。 |
| REVIEWING | 复核中 | 旧复核流程状态。 |
| REVIEWED | 已复核 | 旧复核完成状态，部分历史分配记录仍可能使用。 |
| CALLBACK_SUCCESS | 回传成功 | 旧 SAP/回调结果状态，后续使用 `sap_post_status=SUCCESS`。 |
| CALLBACK_FAILED | 回传失败 | 旧 SAP/回调结果状态，后续使用 `sap_post_status=FAILED`。 |
| ALLOCATION_EXCEPTION | 分配异常 | 历史分配异常状态，当前流程以错误提示/异常记录承载。 |

## 4. 预期到货通知单主状态

| 状态编码 | 中文名称 | 说明 |
| --- | --- | --- |
| CREATED | 创建 | 新建/导入预期到货通知单后的标准初始状态。不得显示为“待收货”。 |
| PARTIAL_RECEIVED | 部分收货 | 部分计划数量已完成收货。 |
| RECEIVED | 完全收货 | 全部计划数量已完成收货。 |
| CLOSED | 订单关闭 | 兼容终态，当前主页面未新增关闭流程。 |
| CANCELED | 订单取消 | 单据取消终态。 |

## 5. 预期到货通知单兼容状态

| 状态编码 | 中文名称 | 兼容原因 |
| --- | --- | --- |
| RECEIVING | 收货中 | 历史收货中状态，当前主流程主要根据数量汇总为部分/完全收货。 |
| BOUND | 已绑定 | 包装/箱托绑定流程保留状态。 |
| ON_SHELF | 已上架 | 上架流程保留状态，当前预期到货主状态不再推荐新增为主链路状态。 |
| SAP_FAILED | SAP 回传失败 | 不建议继续作为订单主状态，后续统一使用 `sap_post_status=FAILED`。 |

## 6. SAP 回传状态

| 状态编码 | 中文名称 | 类型 |
| --- | --- | --- |
| NOT_POSTED | 未回传 | 主状态 |
| SUCCESS | 回传成功 | 主状态 |
| FAILED | 回传失败 | 主状态 |
| POSTED | 已回传 | 兼容状态，历史成功值 |

## 7. 状态字典说明

本轮补齐系统字典类型：

| 字典类型 | 用途 |
| --- | --- |
| `wms_outbound_order_status` | 发运订单主状态和兼容状态。 |
| `wms_inbound_order_status` | 预期到货通知单主状态和兼容状态。 |
| `wms_sap_post_status` | 出入库共用 SAP 回传状态。 |

全量初始化已更新 `sql/02_seed_master_data.sql`。已有库可重复执行 `sql/04_seed_status_governance.sql`；该脚本会 upsert 字典类型，并刷新上述三类字典数据，避免唯一键冲突或重复数据。

## 8. 多语种状态词条说明

本轮补充了 `zh-CN`、`en-US`、`pt-BR`、`es-ES` 四种语言的订单状态和 SAP 回传状态词条。页面筛选中兼容状态会显示兼容标记，例如中文为“待分配（兼容）”；列表和详情状态标签只显示状态名称本身。

## 9. 本轮没有修改的业务流程

- 未修改入库收货逻辑。
- 未修改入库 SN 采集、取消收货、上架逻辑。
- 未修改出库分配、取消分配、拣货、取消拣货、发货、取消发货逻辑。
- 未修改 SAP 回传触发时机。
- 未删除历史状态或历史 demo 数据。
- 未改变库存、系统管理、驾驶舱、工作台等非状态显示业务逻辑。

## 10. 后续建议优化项

- 后续可将状态字典接入前端动态字典服务，减少前端静态状态定义。
- 如业务确实需要“待收货”，建议新增展示态或待办标签，不复用 `CREATED`。
- 可逐步迁移历史 `CALLBACK_SUCCESS/CALLBACK_FAILED/SAP_FAILED` 数据到订单状态与 `sap_post_status` 分离模型。
- 可在系统管理中增加字典数据专门维护视图，支持按字典类型查看和维护明细。
